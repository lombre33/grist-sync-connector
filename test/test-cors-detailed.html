🧪 Test CORS Détaillé - Grist Sync

Tests pour contourner les blocages CORS avec Grist API

ℹ️ Info : Ce widget teste différentes approches pour communiquer avec l'API Grist. Les tests 1-3 utilisent une clé API manuelle (avec CORS). Les tests 4-7 utilisent getAccessToken() (sans clé API visible).

CONFIG Configuration de la clé API

1️⃣ Test Preflight OPTIONS

Vérifie si le serveur autorise les requêtes CORS

2️⃣ Récupérer infos du document (clé API)

GET /api/docs/{docId} avec Authorization header

3️⃣ Récupérer les records (clé API)

GET /api/docs/{docId}/tables/Table1/records avec Authorization header

4️⃣ Obtenir un Access Token

🔐 Cette approche ne nécessite PAS de clé API ! Utilise grist.getAccessToken() qui récupère un token directement depuis Grist.

5️⃣ Récupérer infos du document (Access Token)

GET /api/docs/{docId}?auth=TOKEN (pas d'Authorization header)

6️⃣ Récupérer les records (Access Token)

GET /api/docs/{docId}/tables/Table1/records?auth=TOKEN

7️⃣ Lister les tables (Access Token)

GET /api/docs/{docId}/tables?auth=TOKEN
